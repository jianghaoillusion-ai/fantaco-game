# 角色重畫草稿 v2

這是給我的王看的草稿，尚未核准。姐姐揮手、哈特扶帽、精靈攤掌只是動作提案。不可直接合併或當成正式角色定版。

從 `xiaosong/cast-redraw` 的 `24e9eba` 開出 `xiaoxia/cast-redraw-v2`。本輪只換三張全身 PNG；不更新 expr、頭像、WebP 或遊戲的角色尺寸設定。因此本輪不是遊戲畫面整合驗收。以 main 為 base 的 PR 會包含來源分支原本尚未合併的變更，本輪範圍請以 `24e9eba..HEAD` 檢視。

## 來源與工具

舊設定依 `git show 525ab99^:assets/chars/<id>.png` 取得；畫風參考來源分支的飛飛、阿飄、西卡、布魯。使用 Codex 內建 image_gen 重畫，Pillow / NumPy / OpenCV 只做透明邊緣雜點清理、整張等比縮放、540×720 畫布置中和量測對照。沒有把舊頭貼大、沒有非等比拉伸。沒有使用即夢、付費 API、綁卡、新安裝工具、Chrome 或 AppleScript。

生圖要求：三人維持舊服裝、配色、髮型辨識；姐姐柔和杏眼、彎眉、開口笑；哈特圓眼、挑眉、露齒笑；精靈斜向較細眼、不對稱眉、單側嘴角笑。先各生成，再依實際結果要求重畫短身體、收窄頭髮／捲髮；比例不合的候選不交付。內建生成原檔由工具自動存內建磁碟，交付後清除本輪生成暫存，最終檔留外接碟。

## 量測方式與限制

七張同為 540×720 RGBA。統一 alpha ≥ 128。`landmarks.json` 是人工逐張描定的可見頭部／頭髮範圍，與 alpha 遮罩相交後計算實際像素數，不用外框矩形面積代替。`*-head-mask.png` 和 `mask-audit.png` 可直接檢查圈選。面積包含耳朵及下巴以下可見長髮，排除手、頸部、帽子、球冠與蝴蝶結；被衣服或帽子遮住的頭髮不推算面積。

頭高是髮頂／頭皮到下巴，不是長髮末端。西卡頭頂被貼頭棒球帽遮住，頭高依貼頭帽頂推估頭皮，面積仍排除紅帽；其面積偏小，不可據此宣稱實際頭顱最小。飛飛髮箍／髮夾貼在頭髮內，不增加外框。臉寬以可見兩頰外緣量，不含耳朵和頭髮，與舊報告的估值不能直接混比。座標人工判讀約有 2–5 px 誤差，面積是可重算的可見範圍估計，並非精密解剖測量。

對照圖採七人完全相同的 0.92 倍縮放、腳底對齊，沒有把身高各自拉成一樣；臉部圖也採相同的 1.2 倍放大。原圖的身高差、頭寬差會保留。重算：在已有 Pillow/NumPy 的 Python 環境執行 `python docs/cast-v2/build_comparisons.py`。

四位基準的頭髮長短不一，面積本來就不同。不能只因新圖落在四人最小至最大之間就宣稱一致，仍須同時看短髮三人及臉部放大圖。精確數字見 `measurements.md`。

## 仍未達標／待我的王決定

頭身比三張皆在 0.32–0.36，但「頭高、臉寬、含髮寬及面積全部一致」尚未達成。哈特含髮寬 252 px，相對短髮基準 204–211 px 約大 19–24%；臉寬 166 px 也較寬。精靈收髮後頭高 207 px，比基準 220–225 px 小約 6–8%，含髮寬 195 px 略小。姐姐頭高 228 px、臉寬 155 px 接近基準，但長髮面積不能等同短髮。

姐姐長髮收到肩膀附近；哈特黑帽帽冠變矮，與舊版高帽的辨識度仍需我的王看過。服裝主要配色與元素保留，但細節簡化，不是逐筆複製。三張繪畫仍有新舊批次的線條／陰影差異，不宣稱畫風完全相同。

檔案、對照圖和量測可供草稿審閱，以上視覺差異尚未通過正式驗收。本輪不合併、不發布、不更新正式遊戲資產引用。

小頌已目視檢查對照圖和遮罩，結論是可供草稿審閱、不能宣稱全部規格通過。小頌的工作階段無法重跑 alpha 量測，所以數字與透明尺寸由小夏的本機程式實測，不冒稱兩人獨立重算。已修正對照圖標題的字型缺字符號。

另外需注意：三張不含帽冠的身高 628–636 px，對照組 655–657 px，約矮 3–5%。姐姐比例在使用者容許值內，但高於參考組；這兩件事不能互相替代。哈特臉寬 166 px，相對基準 141–151 px 大約 10–18%。精靈縮捲髮、金珠上衣和本輪不更新 expr／頭像都是使用者明訂要求，不列為漏做。

小頌第二次直接讀取小夏依 `525ab99^` 匯出的三張舊圖，修正了第一輪誤判：姐姐桃紅上身仍保留；縮捲髮及金珠符合本輪要求；姐姐 0.3585 在容許值內；expr／頭像是後續整合項目。仍指出服裝細節有漂移：姐姐領巾改成荷葉領及小蝴蝶結，上身和袖口亮片簡化；哈特帽頂較平、黃色菱格增多；精靈的彩球縮小、深藍織紋與袖口流蘇改成較簡化的亮藍黃邊。這些不能當作已完全保留舊服裝，需繼續修稿或由我的王決定。交叉檢查結論維持「可看草稿，未通過正式驗收」。
