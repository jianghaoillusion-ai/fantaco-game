## 製作與提示

使用 Codex 內建 imagegen 共10次，加本機 Pillow/NumPy/OpenCV。沒有即夢、點數、付費API、新安裝、AppleScript或Chrome操作。原設定取 `525ab99^:assets/chars/<id>.png`。

最後採用：姐姐第4張的頭與第2張的完整身體、哈特第3張、精靈第3張。所有來源1086×1448，去掉不相連透明雜點後等比縮小，平移到540×720，腳底y685。姐姐右臂另取本輪第2張等比處理候選，於原位置合成，接縫羽化1.2px，後以本機OpenCV局部補掉袖子前方殘留髮線及修齊袖緣；沒有非等比拉伸。中途試過局部等比放大頭部與另排皇冠，但最後三張沒有採用這些版本。

最後提示重點：姐姐保持長直髮、圓眼張嘴笑和頂部結，縮窄臉與右肩、長髮藏在軀幹後；哈特保留中分棕髮、大圓眼、細弧眉、尖鼻亮點和寬笑嘴，只加寬紅袖肩及移帽；精靈保留短毛絨藍髮、黑短眉、直向橢圓眼、小圓鼻與小笑嘴，肩膀回補適量、腰帶下移、站直對稱。未採用候選不作定版依據。

## 重建與量法

執行 `~/media-tools/venv/bin/python docs/cast-v2/build_comparisons.py`。只讀資產，重建 `review/cast6/` 和 docs 既有對照。程式本體是 `measure_cast6.py`。

本輪座標正本是 `review/cast6/landmarks.json`。本資料夾舊的 `landmarks.json` 保留給未改的飛飛、阿飄、西卡；那三人的對照數字沿用cast5，已標「舊量法參考，未重驗」，髮量未知仍留空。

四位重算：alpha≥128；可見頭部取下巴以上最大連通塊，人工多邊形扣帽冠蝴蝶結和手。臉以兩頰9×9中位數取樣、CIELab ΔE≤18，取最大膚色連通塊並補洞；耳朵分區另算，沒有推算被瀏海遮住的額頭。髮量為頭部扣臉耳，再加入下巴以下多點同色、8連通到頭髮或人工指定可見髮束種子的區塊（袖子遮住中段時不能硬要求連到頭頂）。樣本另取左右長髮暗部，避免只取瀏海亮部漏算。不是三維體積。頭高與總高採含首尾像素的+1定義。

肩寬在固定y280取外輪廓；布魯包含上臂。中線採兩眼中點的人工座標。抬手側無法量，不能由單側推算雙側。補列下巴+34的單側肩寬供檢查。身長是下巴到腰；胯下受衣襬遮蔽者標估計，姐姐裙下腿根留空。

差距始終對照小頌cast5基準數字，不改基準讓結果過關。本次布魯重算頭高217 vs 舊216，髮量16412 vs 舊16260，並排揭露；頭部面積32965相同。每張圖的SHA1、批次碼在measurements.md/json，最終commit寫在外部交付報告。
