# PR #5 三人全身重畫草稿（cast5）

這輪重新生成姐姐、哈特、精靈的整個身體，沒有沿用舊身體只換頭。仍未達成「每項對布魯 ≤5%」，不能合併或當定版。動作仍是未核准提案：姐姐揮手、哈特扶帽、精靈雙手攤掌。精靈正面站立，頭、軀幹及腿的中線接近垂直，雙臂採對稱構圖；不是像素鏡射。

只更新三張 `assets/chars/*.png` 和本資料夾／兩張對照圖。不修改四位基準、expr、頭像、WebP、遊戲尺寸或正式部署。

## 製作

僅使用 Codex 內建 imagegen、已有 Pillow/NumPy/OpenCV；沒有即夢、付費 API 或新安裝。原設定取自 `525ab99^:assets/chars/<id>.png`。以布魯作全身比例與線條模板，舊圖作服裝辨識參考。逐輪修正整體比例、腰線、肩寬、精靈站姿與表情，並補回精靈的泡泡袖、彩球、金珠及藍白紋褲。

選定生成圖全部為 1086×1448，先清掉不相連的透明雜點、把 alpha ≥245 的內部像素設為255，再統一 0.5 倍縮為543×724，平移至540×720透明畫布，腳底 y685。沒有非等比拉伸、局部拉長腿或把舊頭貼大。姐姐平移(-2,-5)，哈特與精靈(-2,-6)。精靈最高紅球的頂緣裁切已用本輪另一候選的完整紅球修正，只更換裝飾球，未改人物比例。

生圖提示重點：布魯髮頂約30、下巴249、腰帶393、腳底685；頭高220、臉寬141、含髮寬204；姐姐閉嘴柔和笑／杏眼，哈特挑眉張嘴笑，精靈圓眼開心笑，不能斜眼壞笑。帽冠蝴蝶結不算頭。要求服裝原配色、細彩色描邊、全身透明圖。具體生成過程有多次未採用版本，未保留暫存候選。

## 可重算量測

執行 `python docs/cast-v2/build_comparisons.py`（需 Pillow、NumPy，字型使用 macOS 黑體）。程式只讀角色圖，不改資產。

`landmarks.json` 為人工描定座標。alpha ≥128；頭部面積是頭髮、臉、耳輪廓與 alpha 相交後的像素數，包含可見長髮，不含帽冠蝴蝶結、手、頸部。`face_region` 圈掉含五官的臉與耳，剩下為可見髮量估計；不是三維髮量。三位非布魯的既有參考角色尚未分割髮量，不以空值冒充零。

頭高＝自然髮頂到下巴；總高＝自然髮頂到最低鞋底；肩寬＝人工辨識肩與袖子接合處的水平距離（排除手臂、蓬袖外框）；身長＝下巴到腰線中心；腿長＝可見褲襠到鞋底。姐姐的腿根被裙子遮住，腿長不可直接驗證，另列「腰到鞋底」參考值，不把它當腿長或宣稱通過。飛飛與阿飄腰線被衣服遮住，也留空。

人工輪廓約有2–5像素判讀不確定性，帽子遮住的髮量無法補算。肩線也受衣服及動作影響。表內接近5%的數字不是精密解剖驗收證明；不把誤差當作放寬門檻的理由。差距直接以同尺寸原圖數字對布魯計算，不先各自除以身高。頭身比使用未四捨五入的數值計算，避免姐姐剛好−5%被顯示精度誤標成−5.01%。

`mask-audit.png`：粉色覆蓋頭部計數範圍，綠線肩寬、橘線腰線、紫線腿根。全身對照採1:1、七人同一鞋底線；臉圖採1:1、同一下巴線。三張 `overlay-*-vs-blue.png` 各50%透明、只平移對齊鞋底，沒有另縮放個別人物。

## 尚未達標

完整數字見 measurements.md。姐姐可見髮量+24.12%、身長+6.94%、頭部面積−5.14%；精靈可見髮量+36.65%、臉寬−5.67%、頭部面積+5.28%。哈特可見髮量−5.46%、可見頭部面積−4.36%，但有帽子與手遮蔽，完整髮量與頭部無法驗證，不能判成通過或確定真的較少。姐姐腿長無法直接驗證。髮量是人工分割估計，保留可檢查的輪廓，不宣稱生理體積測量。

造型仍有未授權變動：姐姐看起來像短髮，只剩細髮束，未保留原長髮輪廓；哈特高帽縮成後側小帽，大衣縮短；精靈高球冠縮小、褲子較窄。精靈藍金色仍比原圖鮮明，姐姐眼線較成熟。帽冠的高度、保留長髮與相同可見髮量，在固定畫布內尚未同時解決。這些都不是已核准的設計取捨。

PR維持Draft，只推 `xiaoxia/cast-redraw-v2`，不merge、不推main。這輪是未完成視覺驗收的草稿修訂，沒有宣告專案改版結案／發版，不建立正式tag或另做安裝包。

## 最終修正與交叉審查

Pillow 只取本輪另一生成候選的完整紅球，等比縮小後替換冠頂裝飾球。人物與量測數值不變。這是唯一局部貼合；身體未拉伸。

小頌透過 xiaosong-xiaoxia-collab 做唯讀目視與座標手算核對，沒有跑像素遮罩程式，面積及髮量不是兩人獨立重算。結論：未通過。姐姐頭高／頭身比剛好−5%、含髮寬−4.90%均壓線，不能當穩定通過。姐姐腰線已接近布魯，身長差主要來自下巴較高，不能只再縮身體。肩線受舉手與袖型影響，四人量測高度不同（布魯273、姐姐263、哈特263、精靈267），只能當可檢查的近似量。

哈特帽子和手遮住部分頭髮，因此表內頭部面積與髮量是可見面積，不能證明遮住部分也一致；姐姐蝴蝶結也有遮蔽。精靈腿根在下襬附近，236px是估計，不能視為精密腿長驗證。髮量是本次使用者明確要求，保留為未達成項目，不採用審查中「髮量不是要求」的誤讀。

尚未整合說話動畫：三人 expr 與頭像仍是舊圖，本輪不更動。核對 js/portraits.js:135–149，正常說話讀取 expr/<id>-<expr>[-open].png，不是直接在新主圖與舊圖之間切換。因此小頌提出的「必然新舊身體跳動／姐姐沒有張嘴」不能直接當已重現故障；正確結論是新主圖尚未接入及驗收，正式採用前需另外重做與主圖一致的表情配對。
