# 眠花糖與魔法氣球物語

FANTACO 魔幻藝術節的免費親子瀏覽器遊戲。把兩個一樣的寶物合在一起，陪飛飛走過《魔法氣球物語》。

試玩：https://jianghaoillusion-ai.github.io/fantaco-game/

完全免費，沒有內購。能量會隨時間回來，每天還有免費禮物。給全家人一起玩。

## 怎麼玩

這是合成遊戲（和 Travel Town、迷霧小鎮、Foodstars 同一類），不是消消樂：

1. 點一下「產生器」（帶閃電的窩或箱子），花 1 點能量，跳出道具。
2. 把兩個一樣的道具拖在一起，合成更高一級。
3. 把角色訂單要的東西拖過去，換星星種子和經驗。
4. 完成故事訂單，打開下一章。平常的訂單會一直出，可以一直玩。

能量上限 80，約每 90 秒回 1 點。沒有廣告、沒有儲值。

## 每週加新章

內容是資料驅動的。新的一章通常只要改這些 JSON：

- `data/chains.json`：合成鏈與產生器
- `data/chapters.json`：章節、背景、音樂
- `data/story-orders.json`：故事訂單與對白

不必改程式。之後還會接到怕黑的布魯，以及最後一願送給哈特。

## 美術與音樂

眠花糖使用官方 3D 模型（TuZi.obj 精簡為約 0.5MB 的 GLB，平塗填色＋深藍描邊，接近主視覺線條）在主畫面跳動；官方主視覺三視圖仍作為載入失敗時的備案。角色立繪依《演員介紹卡》官方劇照重繪成可愛 2.5D 風格。所有合成階梯與產生器改為有光澤、陰影和稀有度光暈的繪製卡面；部分階梯道具為延伸創作，會在資料裡標示。版面支援劉海／Dynamic Island 與底部橫條安全區（viewport-fit=cover）。章節配樂為原創短旋律；過關時播放的是官方〈飛向藍藍天〉錄音的副歌片段（從「飛向藍藍天_MMM v1.wav」第 72–100 秒擷取）。
