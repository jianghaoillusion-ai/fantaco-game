# 眠花糖與魔法氣球物語

FANTACO 魔幻藝術節的免費親子瀏覽器遊戲。把兩個一樣的寶物合在一起，陪飛飛走過《魔法氣球物語》。

試玩：https://jianghaoillusion-ai.github.io/fantaco-game/

完全免費，沒有內購。能量會隨時間回來，每天還有免費禮物。給全家人一起玩。

## 怎麼玩

這是合成遊戲（和 Travel Town、迷霧小鎮、Foodstars 同一類），不是消消樂：

1. 點一下「產生器」（帶閃電的窩或箱子），花 1 點能量，跳出道具。
2. 把兩個一樣的道具拖在一起，合成更高一級。
3. 把角色訂單要的東西拖過去，換星星種子和經驗。
4. 完成故事訂單，打開下一章。平常的訂單會一直出，可以一直玩。

能量上限 80，約每 90 秒回 1 點。沒有廣告、沒有儲值。

## 每週加新章

內容是資料驅動的。新的一章通常只要改這些 JSON：

- `data/chains.json`：合成鏈與產生器
- `data/chapters.json`：章節、背景、音樂
- `data/story-orders.json`：故事訂單與對白

不必改程式。之後還會接到怕黑的布魯，以及最後一願送給哈特。

## 預覽版先做了什麼、什麼先留位置

已做：本機暱稱與自訂名稱、localStorage 存檔（含舊版存檔轉移）、7×6 合成棋盤、產生器、能量回復、每日免費禮物、角色訂單（故事＋無限隨機訂單）、收集冊與稀有度、背包、星星種子、兌換禮品頁（顯示「即將開放」）、章節地圖、每章音樂、設定裡的音樂／音效開關、過關／升級時的〈飛向藍藍天〉歌詞與慶祝音樂、官方眠花糖三視圖動畫。

先留位置、這一版還沒接上：

- Google／電子信箱登入（見 `js/auth.js`）
- Cloudflare Workers + D1 雲端存檔（見 `js/save.js` 的 `syncCloud`）
- 星星種子換實體禮品（不蒐集地址）
- 現場活動兌換碼／QR（系統欄位預留，不上線）
- 官方〈飛向藍藍天〉錄音檔（若放到 `assets/audio/feixiang-sting.ogg` 會自動改用；現在先播原創的慶祝旋律，並顯示官方歌詞）
- 官方 3D 模型（檔案太大，不適合手機網頁；畫面使用官方三視圖精靈動畫）
- 布魯、哈特與之後每週新章

## 美術與音樂

眠花糖與貼紙來自官方設計檔（主視覺四個角度當作三視圖；貼紙經過去背做成合成圖鑑）。其他角色為配合線條風格的原創簡筆，非正式劇照。章節背景與部分中間階道具為延伸創作，會在資料裡標示。章節配樂與音效為原創短旋律，不是官方主題曲的旋律。
