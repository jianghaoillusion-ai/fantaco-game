# 眠花糖與魔法氣球物語

FANTACO 魔幻藝術節的免費親子瀏覽器遊戲。把兩個一樣的寶物合在一起，陪飛飛走過《魔法氣球物語》。

試玩：https://jianghaoillusion-ai.github.io/fantaco-game/

完全免費，沒有內購。能量會隨時間回來，每天還有免費禮物。給全家人一起玩。

## 怎麼玩

這是合成遊戲（和 Travel Town、迷霧小鎮、Foodstars 同一類），不是消消樂：

1. 點一下「產生器」（帶閃電的窩或箱子），花 1 點能量，跳出道具。
2. 把兩個一樣的道具拖在一起，合成更高一級。
3. 湊齊角色訂單要的東西，點綠色的「交給他」，換金幣、星星種子和經驗。
4. 用金幣打開棋盤上的木箱迷霧，讓可以玩的格子變大。
5. 點「地圖」用金幣和星星種子打開新地區、修復小建築。點「小舖」可用同一種貨幣換道具或回復能量。點「魔法袋」打開背包。
6. 完成故事訂單，打開下一章。平常的訂單會一直出，可以一直玩。

能量上限 100，約每 90 秒回 1 點。完全免費，沒有廣告、沒有儲值，也不能用真實的錢買東西。

## 每週加新章

內容是資料驅動的。新的一章通常只要改這些 JSON：

- `data/chains.json`：合成鏈與產生器
- `data/chapters.json`：章節、背景、音樂
- `data/story-orders.json`：故事訂單、對白與訂單小句子
- `data/map.json`：世界地圖地區、解鎖花費、建築修復與小舖商品

不必改程式。現在已接到怕黑的布魯、最後一願送給哈特，以及終章「漫天氣球」。地圖從微笑村、微笑城堡出發，之後還有和飛飛、阿飄、西卡、哈特、氣球精靈有關的新地區（標了「新創作」的是延伸創作）。之後每週只要在 `data/map.json` 加一個地區就能進來。

## 美術與音樂

主畫面的眠花糖以官方平面主視覺為主，會彈跳、壓扁拉長、輕輕搖耳朵，並不時轉到側面或背面讓尾巴黃星看得見；合成或完成訂單時會換成跳躍姿勢並冒出星星閃光。官方 3D 模型（TuZi.obj 精簡為約 0.5MB 的 GLB）仍留在專案裡，僅在手動開啟時作為備案。角色立繪依《演員介紹卡》官方劇照重繪成統一的 Q 版／中頭身 2.5D（Travel Town 風格），不是寫實人像。所有合成階梯與產生器改為有光澤、陰影和稀有度光暈的繪製卡面；部分階梯道具為延伸創作，會在資料裡標示。版面以手機與平板為主，支援劉海／Dynamic Island 與底部橫條安全區（viewport-fit=cover），棋盤格數會跟著可用空間改變。章節配樂為原創短旋律；過關時播放的是官方〈飛向藍藍天〉錄音的副歌片段（從「飛向藍藍天_MMM v1.wav」第 72–100 秒擷取）。
