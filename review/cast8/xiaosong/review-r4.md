# cast8 交叉檢查 r4（小頌）

範圍：只看 commit cf8da24 新增的 4 張 4 倍證據圖，對應 r3 的圖面疑點。
**未獨立實跑：** 這輪沒有跑任何程式、沒有量像素，只用眼睛看圖。「alpha≥128 輪廓與比例數字不變、哈特 0 差」引用小夏的重跑結果，我沒有自己核對。
四張圖都沒有標「前／後」。下面的判讀假設左邊是修改前或原設定，右邊是 cast8 現版。

| 疑點 | 證據圖 | 判定 |
|---|---|---|
| r3-1 姐姐頭右側灰白半透明殘影 | jiejie-right-fringe-4x | **解除。** 深色底上的輪廓乾淨，沒看到連在主體上的灰色塊。白底上只剩 1～2 px 的反鋸齒邊，下緣有一縷略淡的髮尾，看起來是髮絲本身，不是殘影。 |
| r3-3 姐姐右側頭髮小白點 | jiejie-right-neck-4x | **解除。** 左圖右上那條亮縫和亮點，在右圖已經變成連續的髮紋，衣領邊沒有被影響。 |
| r3-4 精靈臉寬端點 | spirit-face-width-4x | **解除。** 綠線兩端都停在臉頰膚色和深色輪廓的交界。右端在尖耳前面那撮深色頭髮的內側，左端也沒有碰到耳朵。臉寬 130 的量法成立。 |
| r3-2 姐姐左臉頰外緣亮邊 | jiejie-cheek-source-4x | **部分解除。** 輪廓線內側的淺色邊，原設定等比放大後也有，這點同意。但右欄 cast8 還有兩處是原設定沒有的：① 深色輪廓**外側**有一條偏灰白的直條（右欄最左邊，4 倍圖 x≈122～135），原設定那個位置是深棕色頭髮；② 右欄下方有一小塊灰色帶描邊的碎形（4 倍圖約 x145～165、y195～215）。這兩處要說明是什麼：是手指、底色，還是殘影。 |
