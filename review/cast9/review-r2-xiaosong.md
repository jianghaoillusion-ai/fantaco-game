## 2. 需要明列的取捨與風險

1. **頭身比降到 0.298（布魯 0.3305）。** 頭面積 33341 跟布魯的 32965 幾乎一樣，但主要是頭髮撐出來的。臉面積只有 9978，布魯是 16159，約 0.62 倍；臉寬 124 對 134，約 0.93 倍。和布魯站一排時，姐姐的**臉會明顯比較小**。瀏海蓋住額頭會讓臉面積偏低，所以 0.62 倍有高估差距的成分，但方向是對的。這點請寫進取捨，交給我的王用眼睛看排排站的效果決定。
2. **腿露出來的長度比原設定短很多。** 目視估算：原設定從紗裙底到鞋底約占全身 0.30，這版約 0.19～0.24，腰到腳占全身約 0.46（原設定約 0.6）。如果目標是跟布魯對齊（腰到腳 291/655≈0.44），這是有意的改變。但要明講「原設定的長腿比例沒有保留」，不能寫成「恢復原設定」。
3. **蝴蝶結算進全身高。** 含蝴蝶結全高 663，alpha 最上緣大約在 y22。目前 540×720 畫布裝得下，上方剩約 22 px。

## 3. 量測腳本的問題（不影響圖，影響數字可信度）

1. **`count-sock-stripes-r2.py` 只數了原設定，沒數候選圖。** 座標寫死成 origin/main 的 x219～297、y514～580。請用同一套規則，換成候選圖自己的襪子座標（目視大約左腳 x200～245、右腳 x285～330、y565～620）再跑一次，兩邊都數出 3 才算定案。這輪候選圖的「3 條」只能算目視結果。
2. **腿寬比 0.943 的取樣列跨到鞋子。** 候選圖的鞋口大約在 y625，y632 那列已經量到鞋子上緣（寬 51）。y572 落在襪口。建議改用兩邊都在小腿或襪身中段的列，或者分開報告「襪身」和「鞋口」兩組。
3. **`normalize-r2.py` 只保留最大的連通塊。** 跟身體分開的髮絲尖端或亮片碎點會被直接刪掉。請在 JSON 補一欄「被刪除的像素數」，確認被刪的只有雜點。
4. 頭區多邊形左緣 `[204,147]→[194,199]` 貼著揮手的手。若手指背後有頭髮，會被切掉一點，影響很小，記一筆就好。
