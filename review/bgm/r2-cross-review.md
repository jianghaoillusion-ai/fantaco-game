## 還要改的（文字，不必重新合成）

1. **程式裡寫的旋律和實際播出來的不一樣。** `bar_events()` 用 `notes[j%len(notes)]` 對音符，旋律表的音數和節奏型的音數不一致時，多的音被丟掉，少的就從頭再拿。三首都有這情形：
   - A：第 7、8、12、13、15 小節
   - B：第 5、6、8 小節和第 9–16 小節大半（因為 `4+bar%3` 是 3 小節一輪，對不上 8 小節）
   - C：第 5–8、14–16 小節

   第 49 行註解寫「Match note count to each hand-written rhythm」，跟實際情況不符。量測沒問題，因為驗證程式用的是實際播出的音符，但讀程式的人會以為旋律表就是播出來的音。請改註解，或把旋律表改成和節奏型一樣多的音。

2. **B 的「行走撥弦低音」寫錯。** 程式是根音、三音、五音、三音的分解和弦，請改成「分解和弦低音」。

3. **C 的「短鼓低音」寫錯。** 程式用的是有音高的 `wood` 音色，跟 A 的木琴琶音、C 的木琴應答是同一個音色函式，不是鼓。請改成「木質短低音」之類，並註明 A 和 C 共用 `wood` 音色、但寫法不同。
